# Wireframe VeggiePOS

## File Utama

Prototype wireframe visual ada di file berikut:

- `wireframes/veggiepos-wireframe.html`

## Halaman yang Sudah Dibuat

Wireframe saat ini mencakup 7 layar inti:

1. `Login`
2. `Dashboard Admin`
3. `Data Sayuran`
4. `Transaksi Kasir`
5. `Data User`
6. `Laporan Penjualan`
7. `Laporan Stok`

Ketujuh layar ini dipilih karena mewakili alur paling penting pada VeggiePOS:

- masuk ke sistem
- melihat kondisi toko
- mengelola produk
- mengelola user
- memantau penjualan
- memantau stok
- menjalankan transaksi

## Arah Visual

Konsep desain yang dipakai:

- `Organic Editorial`
- `Market-inspired`
- `Clean POS layout`

Ciri utamanya:

- warna bumi dan hijau sayur
- heading bergaya editorial
- panel data yang rapi dan mudah dipindai
- komposisi admin yang tenang
- komposisi kasir yang cepat dan fokus aksi

Detail visual yang sudah dipoles:

- breadcrumb dan context bar pada tiap layar
- kartu statistik dengan sparkline placeholder
- filter chip dan segmented controls
- panel insight, progress inventory, dan metadata transaksi
- preview struk dan status operasional yang lebih realistis

## Fungsi Wireframe Ini

Wireframe ini dipakai sebagai acuan sebelum implementasi agar:

- struktur tiap halaman sudah jelas
- komponen utama sudah terlihat
- arah desain visual website sudah disepakati
- proses coding nanti lebih cepat dan minim bongkar ulang

## Lanjutan yang Disarankan

Setelah wireframe ini disetujui, tahap berikutnya yang paling pas adalah:

1. memilih stack implementasi website
2. mulai membangun layout dan komponen berdasarkan wireframe ini
3. menurunkan wireframe ini menjadi halaman implementasi yang responsif dan siap data
